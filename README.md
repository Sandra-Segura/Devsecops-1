# Devsecops-1

Proyecto base para pruebas de DevOps. Solo JavaScript, HTML y CSS, sin dependencias externas.

## Estructura

```
public/        Frontend estático (HTML, CSS, JS)
src/server.js  Servidor Node (archivos estáticos + /health)
test/          Pruebas con node:test
```

## Uso

```bash
npm start      # http://localhost:3000
npm test
```
